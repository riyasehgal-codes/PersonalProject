# Boyfriend Day 🌼
```
npm install
npm run dev      # local preview
npm run build    # outputs dist/ — drag dist/ into app.netlify.com/drop, or deploy via Vercel
```
- All text/songs/coupons/letters: `src/data.js`
- Photos: put in `public/images/`, then `img:"/images/us1.jpg"` in data.js
- Colours & styling: `src/styles.css` (CSS variables at the top)
- Sections: `src/components/`
